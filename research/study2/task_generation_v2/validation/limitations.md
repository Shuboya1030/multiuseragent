# 本批未验证项与设计取舍

- 本批是6个代表工作流，不能满足60模板的全部覆盖配额，也没有人为宣称完成配对覆盖。
- 共享角色附加职责属于本实验组织设定，保留TAC原职位；不声称是TAC官方所有任务共用的权限定义。
- Must Low不涉及额外审批；当前财务映射由同一持有人维护，separation按aligned计0。Medium的金额权限是条件分支，计2，而非1。
- Must Medium/High的“放行/mandate”字段可能让Agent推断需要授权。这是交付业务数据的一部分；任务文本没有请求求助或点名联系人，但是否仍有强提示需独立审核。
- Optional Low的收益是活动专属合法素材，字段采用asset ID且不需要实际设计图片。该收益较窄，后续现实性审核可能要求更具体的视觉资产。
- Optional High按结构需2次归属查找，且需组合课程与员工安排发现收益。是否能凭职位捷径找到HR尚未用title-only resolver验证，难度High是拟定值。
- 参考答案不证明V-only绝不可能猜中H；类别依据是信息不可得，不是猜中的概率为零。
- NPC仅持有本人私有记录，依赖靠策略提示约束；不能可靠验证Agent转述的上游证据真实性。需要未来独立执行验证，当前没有防伪服务器状态机。
- 不向NPC发送测试消息；因此没有LLM拒绝、修复、转介的行为证据，也没有新的模型费用。
- 部署使用任务独立OwnCloud路径，R0/R1同任务路径按顺序覆盖，最终R1。一次正式episode只应加载一种条件、一个任务场景，并隔离聊天与工作区。
- OpenHands execution 与官方reset服务未运行；仅镜像/任务接口与真实OwnCloud部署验证。详见README。
